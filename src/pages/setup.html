Set up a new Google connection
  1. Open the reservations sheet. Choose Extensions → Apps Script.
  2. Replace the default editor code with the code below, then save.
  3. Select and run setup. Approve Google’s requested spreadsheet access. Copy the connection secret shown in the spreadsheet dialog. It is stored in Google Script Properties; keep it private.
  4. For an existing connection, choose Deploy → Manage deployments → Edit → New version, then deploy to keep the same URL. For a new connection, choose Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone, then deploy. The service checks the secret on every reservation request, and the spreadsheet itself remains private.
  5. Paste the web app URL ending in /exec and the connection secret below. The site verifies the correct sheet before saving.

The secret is encrypted on the server and is never sent to players’ browsers. Switching players on the calendar remains an honor system.
